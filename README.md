# 公開鍵暗号方式のしくみ（教育用）

対になる2つの鍵（公開鍵と秘密鍵）を使う **公開鍵暗号方式** のしくみを、鍵を自分で動かしながら学ぶ教育用の Web アプリです。共通鍵暗号方式との違いも確かめられます。

## 学べること

教科書（情報 I「安全な通信」）の公開鍵暗号方式の範囲を、全4章・12枚のスライドで、自分で操作しながら学びます。ほとんどのスライドに「🎯 やってみよう」（操作の課題）があり、クリアすると次のスライドへ進めます。

1. **公開鍵暗号方式とは**：共通鍵暗号方式の課題（鍵を渡すと盗まれる）のふり返り、秘密鍵と公開鍵（だれが持つか）、片方の鍵で暗号化したものは対になるもう一方の鍵でしか復号できないこと、公開鍵から秘密鍵を探し当てるのは困難なこと
2. **公開鍵暗号方式のしくみ**：受信者が鍵のペアを作る → 送信者が受信者の公開鍵を手に入れる → 受信者の公開鍵で暗号化 → 暗号文で送る → 受信者が自分の秘密鍵で復号、の手順。盗聴者は公開鍵を手に入れても復号できないこと
3. **どの鍵を使う？**：A さんが B さんに送るとき暗号化に使う鍵を選ぶ、送信者が自分の秘密鍵で暗号化したときの問題点
4. **共通鍵暗号方式との違い**：鍵の数・鍵を渡す問題・処理の速さ・代表例（AES と RSA 暗号）の仕分け、8問のまとめテスト（採点・見直し付き）

### さわって確かめる（いろいろな操作）

| 操作 | スライド |
| --- | --- |
| **ドラッグ** | 共通鍵・公開鍵・暗号文の札を A さんと B さんの間で送る（公開鍵は B → A、途中で盗聴者がコピーする）／公開鍵と秘密鍵を「公開」「金庫」に置く／鍵の札をメッセージに重ねて暗号化・復号する／特徴のカードを共通鍵暗号方式・公開鍵暗号方式に仕分ける |
| **ダブルクリック** | 鍵を作る機械で、公開鍵と秘密鍵のペアを作る |
| **マウスホイール** | 盗聴者になって、公開鍵から秘密鍵の候補を次々に試す |
| **カーソル移動** | 盗聴者になって、虫めがねで通信路を流れる公開鍵と暗号文をのぞき見る |
| **クリック・タップ** | 手順を並べる／問題に答える |

ドラッグの操作は、タップで選んでからタップで置く方法でもできます（スマホ・タブレット向け）。

### 問題の種類

- **予想問題**：操作の前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません。正解の位置は問題ごとにばらばらです
- **体験問題**：鍵を正しい場所に置く、暗号化に使う鍵を選ぶ、手順を並べる、特徴を仕分けるなど、自分で操作する問題
- **確認問題**：自分の秘密鍵で暗号化したときの問題点と、最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題や「やってみよう」のあるスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-public-key-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-public-key-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
